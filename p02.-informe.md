### 2. ¿Desde dónde?

Desglose del mega filtro:

```
grep "Failed password" auth.log | grep -oE "from [0-9.]+" | cut -d' ' -f2 \
| sort | uniq -c | sort -rn | head
```

- `grep "Failed password" auth.log`: Filtra las filas del archivo auth.log con el string "Failed password".

- `grep -oE "from [0-9.]+"`: -o imprime solo la parte que matchea el patrón (no la línea completa). -E habilita regex extendida (permite + sin escapar). Resultado: de una línea como Accepted password for sysadmin from 10.0.2.2 port 56484 ssh2, extrae solo from 10.0.2.2.

- `cut -d' ' -f2`: corta cada línea usando espacio como delimitador (-d' ') y se queda solo con el segundo campo (-f2).

Ejemplo: si la entrada (viniendo del grep anterior) es from 10.0.2.2, el campo 1 es from y el campo 2 es 10.0.2.2 → eso es lo que imprime.

- `sort`: ordena las IPs alfabéticamente, necesario para que `uniq -c` pueda agrupar correctamente las repetidas (solo agrupa líneas iguales consecutivas).

- `uniq -c`: cuenta las filas únicas consecutivas y antepone el conteo a cada una.

- `sort -rn`: ordena numéricamente (-n) y en orden descendente (-r), para que las IPs con más intentos queden primero.

- `head`: muestra solo las primeras 10 líneas (las IPs con más intentos fallidos).
